# Social Media Prop 📸✨

## 項目簡介 (Project Overview)
**Social Media Prop** 係一個為香港人打造嘅全方位社交媒體管理平台。我哋嘅目標係幫你用一張相、一個簡單嘅動作，就可以生成唔同風格嘅內容，一次過同步去你所有嘅社交賬號（例如 Instagram, Threads, Facebook 等）。

如果你同朋友去食餐好嘢，影咗張相，**Social Media Prop** 可以幫你：
*   **美食 Account**: 自動生成一張令人口水流嘅野食相同埋配文。
*   **回憶 Account**: 自動生成同朋友聚會嘅感性相，寫低當時嘅 Memory。
*   **心情/天氣 Account**: 根據當時嘅 Mood 同埋天氣，生成一張有氛圍感嘅相。

## 主要功能 (Key Features)
*   **一鍵多發 (Multi-Style Posting)**: 一張原圖，AI 自動轉換成多種風格。
*   **香港本土化 (HK Localization)**: 界面同 AI 生成內容都會用返地道嘅香港粵語/繁體中文，啱晒香港人口味。
*   **整合儀表板 (Centralized Dashboard)**: 一個 Page 睇晒所有 Account 嘅狀態同數據。
*   **AI 風格自定義**: 根據你唔同 Account 嘅定位，設定專屬嘅 AI Prompt 同風格。

## 技術棧 (Tech Stack)
*   **Framework**: Next.js 14+ (App Router)
*   **Runtime**: Bun
*   **Language**: TypeScript
*   **Styling**: Tailwind CSS
*   **Backend/API**: OpenAI / Midjourney / Stable Diffusion (Integration planned)

## 開始使用 (Getting Started)

首先安裝依賴：
```bash
bun install
```

啟動開發伺服器：
```bash
bun dev
```

打開 [http://localhost:3000](http://localhost:3000) 就可以見到個 Dashboard 喇！
